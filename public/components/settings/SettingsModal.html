A chave é testada na Binance e gravada no arquivo .env do servidor, no seu computador. A Secret Key não fica no navegador e não volta para a página.

Como criar a chave na Binance
  1. Entre na sua conta pelo site da Binance e abra Perfil → Gerenciamento de API (em inglês, API Management).
  2. Clique em Criar API, escolha Chave gerada pelo sistema e dê um nome, por exemplo Dashboard. Confirme a verificação de segurança (2FA).
  3. Nas permissões, deixe marcado só "Habilitar leitura" (Enable Reading). Não habilite negociação, margem, futuros nem saques: o dashboard só lê os dados.
  4. Opcional e mais seguro: em Restrição de acesso por IP, libere só o IP do seu computador. Se o seu IP mudar, a chave para de funcionar até você atualizar a lista.
  5. Copie a API Key e a Secret Key. A Secret Key só aparece uma vez; se perder, apague a chave e crie outra.
  6. Cole as duas aqui em cima e clique em Testar e salvar.

Nunca compartilhe a Secret Key. Para trocar de chave depois, é só abrir esta tela de novo.
